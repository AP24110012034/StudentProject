# Student Management System

A **console-based Student Management System** developed in C that allows different users to manage student records efficiently. The system includes role-based access, enabling admins, staff, and guests to perform specific tasks.

---

## Features

- **Role-Based Access**:
  - **Admin**: Can add, view, search, update, and delete student records.
  - **Staff**: Can add, view, search, and update student records.
  - **Guest**: Can view and search student records only.
- **CRUD Functionality**:
  - Add new students
  - View all students
  - Update existing student details
  - Delete student records
  - Search students by roll number
- **File-Based Storage**:
  - Student data stored in `students.txt`
  - User credentials stored in `credentials.txt`
- **Menu-Driven Interface**:
  - Simple console menus that change based on user role
